# Custom Blocks and Items

Add custom blocks and items to your Minecraft world with ease.

## Features

- Adds a custom block
- Adds a custom item

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod JAR file.
2. Place it in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

Once installed, you will find the custom block and item in the game. The custom block can be placed in the world, and the custom item can be used in your inventory.

## Configuration

No additional configuration is required. The mod is ready to use out of the box.
